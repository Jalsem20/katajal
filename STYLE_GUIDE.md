# kataJal — Style Guide

## Brand Identity
- Name: kataJal
- Tagline (BM): kata-kata bermakna
- Tagline (EN): meaningful words
- Tone: warm, literary, trustworthy, calm

## Color Palette
- Background:   #f5f0e8  (warm parchment)
- Surface:      #fffdf8  (off-white card)
- Ink:          #1a1612  (near-black)
- Ink muted:    #7a6e62  (secondary text)
- Accent:       #c0392b  (deep red)
- Border:       #e0d8cc  (warm grey)

## Typography
- Display font: DM Serif Display (quotes, logo)
- Body font:    DM Sans (buttons, labels, UI)
- Quote size:   clamp(1.25rem, 3.8vw, 1.65rem)
- Line height:  1.55

## Components
- Card: rounded 18px, warm shadow, left accent stripe
- Buttons: pill-shaped, dark fill for primary
- Language toggle: pill group, accent active state
- Toast: dark pill, bottom center, 2.2s duration

## Spacing
- Page max-width: 680px
- Card padding: clamp(2rem, 6vw, 3rem)
- Section gap: 2rem

## Interaction
- Transitions: 200–300ms cubic-bezier(.4,0,.2,1)
- Quote swap: fade + translateY(6px)
- Hover: accent color shift on buttons

## Do's
- Keep it minimal — one action at a time
- Always mobile-first
- Warm tones only — no cold blues or purples

## Don'ts
- No generic fonts (Arial, Inter, Roboto)
- No purple gradients
- No heavy animations
- No more than 2 fonts
